AI-assistedBuilt
Orchestration layer (Cowork) Joins the two sources, cross-checks the data, runs the controls, and computes every figure in code — no manual spreadsheets. Salesforce and NetSuite, which don't talk to each other, are joined here. Built and code-complete. Every number is reproducible, with an audit trail. License: cost of the program, not the NGO.

Governance & traceability layer

Read-only

NetSuite and Salesforce in read-only, minimal scope — access being provisioned per system. The AI never writes to the source systems.

Donor data

PII never leaves Salesforce. Segregated per NGO on every connection.

Computed in code

Every figure is calculated deterministically in code, not by the LLM. The AI drafts narrative; the numbers come from code.

Session log

Append-only trace: date, inputs, output, and reviewer. Auditable and handover-ready.
